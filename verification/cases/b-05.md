# b-05

## Description

An AI application was not designed to be accessible, so people with disabilities find it hard or impossible to use. It does not single out or target people with disabilities in any way.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 35, paragraph 108
- Read on: 2026-11-02

## Expected

- Target point: 5.1.b
- Expected label: clear
- Reason: The guidelines say such applications should not be regarded as exploiting the vulnerabilities of persons with disabilities, so a required condition is missing.
