# d-10

## Description

An AI system classifies people's actual behaviour in a crowd, flagging reasonably suspicious, dangerous behaviour suggesting that someone is preparing to commit a crime. A human makes a meaningful assessment of each flag before any action is taken.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 70, paragraph 214
- Read on: 2026-11-02

## Expected

- Target point: 5.1.d
- Expected label: clear
- Reason: The guidelines list it as outside the prohibition because the assessment rests on objective, verifiable facts reviewed by a human.
