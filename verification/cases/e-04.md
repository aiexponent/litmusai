# e-04

## Description

An AI system receives a photo of one person and searches the internet for matching faces, like a reverse image search engine.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 75, paragraph 233
- Read on: 2026-11-02

## Expected

- Target point: 5.1.e
- Expected label: clear
- Reason: The guidelines say this is targeted scraping and question whether the matches form a database, so the prohibition does not apply.
