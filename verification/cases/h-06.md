# h-06

## Description

A system films everyone entering a concert. After an incident at the concert, police run identification on the recorded video, after the event, to find the offender.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 96, paragraph 311
- Read on: 2026-11-02

## Expected

- Target point: 5.1.h
- Expected label: clear
- Reason: The guidelines class this as post (not real-time) remote biometric identification, which point (h) does not prohibit.
