# h-01

## Description

A provider develops a real-time remote biometric identification system and places it on the EU market, selling it to law enforcement customers. The provider does not use the system itself.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 91, paragraph 291
- Read on: 2026-11-02

## Expected

- Target point: 5.1.h
- Expected label: clear
- Reason: The guidelines say point (h) only prohibits use, so placing such systems on the market is not prohibited but is subject to the high-risk rules.
