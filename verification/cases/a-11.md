# a-11

## Description

A language-learning application uses subliminal techniques to help users learn a foreign language faster. It is transparent about this, and users freely and knowingly choose whether to use it.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 42, paragraph 130
- Read on: 2026-11-02

## Expected

- Target point: 5.1.a
- Expected label: clear
- Reason: The guidelines say such a system is not manipulative when it is transparent and respects the user's free and informed choice.
