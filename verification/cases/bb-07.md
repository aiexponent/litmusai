# bb-07

## Description

A user asks an AI image generator for an ordinary picture, and by accident the output includes material that could amount to sexual material involving a child. The user did not seek this and does not use the output for that purpose.

## Source

- Document: Regulation (EU) 2026/1744 (Digital Omnibus on AI), 8 July 2026, OJ L 2026/1744, 24.7.2026
- Location: recital 12
- Read on: 2026-11-02

## Expected

- Target point: 5.1.bb
- Expected label: clear
- Reason: Recital 12 says the prohibition on use does not cover accidental generation or manipulation of such content.

## Notes

Recital 12 states this for both non-consensual intimate material and child sexual abuse material, so it gives one case for each point (see SELECTION.md).
