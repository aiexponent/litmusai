# f-16

## Description

An education institution uses AI eye-tracking software during online exams to follow where students look, for example to detect use of unauthorised material. It does not identify or infer emotions.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 82, paragraph 255
- Read on: 2026-11-02

## Expected

- Target point: 5.1.f
- Expected label: clear
- Reason: The guidelines say this is not prohibited because the system does not infer emotions.
