# c-04

## Description

A national tax authority runs an AI tool over every taxpayer's return to pick returns for closer inspection. Besides relevant data such as income, assets and family members, the tool uses unrelated data such as taxpayers' social habits and internet connections to single out individuals for inspection.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 54, paragraph 166
- Read on: 2026-11-02

## Expected

- Target point: 5.1.c
- Expected label: red
- Reason: The guidelines list it as detrimental or unfavourable treatment in unrelated social contexts prohibited under point (c)(i).
