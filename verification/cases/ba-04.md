# ba-04

## Description

A person uses an AI image tool that lacks adequate safeguards in order to create realistic nude images of an identifiable former partner, who has not consented.

## Source

- Document: Regulation (EU) 2026/1744 (Digital Omnibus on AI), 8 July 2026, OJ L 2026/1744, 24.7.2026
- Location: recital 12
- Read on: 2026-11-02

## Expected

- Target point: 5.1.ba
- Expected label: red
- Reason: Recital 12 says use is prohibited where the deployer uses the system for the purpose of generating such material, including by using or misusing systems that lack adequate preventive measures.

## Notes

Recital 12 states this for both non-consensual intimate material and child sexual abuse material, so it gives one case for each point (see SELECTION.md).
