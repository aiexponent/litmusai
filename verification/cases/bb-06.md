# bb-06

## Description

A marketing agency uses an AI image generator that lacks the safeguards its provider should have put in place. The agency uses it only to create ordinary product images with no sexual content and no depiction of children in any sexual way.

## Source

- Document: Regulation (EU) 2026/1744 (Digital Omnibus on AI), 8 July 2026, OJ L 2026/1744, 24.7.2026
- Location: recital 12
- Read on: 2026-11-02

## Expected

- Target point: 5.1.bb
- Expected label: clear
- Reason: Recital 12 says the prohibition on use does not cover use for lawful purposes, such as other material, even where the system lacks safeguards that the provider should have put in place.

## Notes

Recital 12 states this for both non-consensual intimate material and child sexual abuse material, so it gives one case for each point (see SELECTION.md).
