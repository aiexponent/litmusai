# f-08

## Description

A call centre uses voice recognition to track its customers' emotions, such as anger or impatience, for example to help staff deal with angry callers. Employees' emotions are not tracked.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 81, paragraph 254
- Read on: 2026-11-02

## Expected

- Target point: 5.1.f
- Expected label: clear
- Reason: The guidelines say this is not prohibited by point (f).
