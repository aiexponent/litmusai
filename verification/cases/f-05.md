# f-05

## Description

An AI system reads written text and infers the emotions or sentiment in it, to set the style or tone of an article. It uses no biometric data.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 80, paragraph 251
- Read on: 2026-11-02

## Expected

- Target point: 5.1.f
- Expected label: clear
- Reason: The guidelines say it is not based on biometric data and therefore does not fall within the prohibition.
