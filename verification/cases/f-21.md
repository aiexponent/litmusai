# f-21

## Description

An education institution uses an AI system that detects students talking to each other by phone or other channels during online lectures. It does not infer emotions.

## Source

- Document: Commission Guidelines on prohibited AI practices, C(2025) 5052 final, 29 July 2025
- Location: page 83, paragraph 255
- Read on: 2026-11-02

## Expected

- Target point: 5.1.f
- Expected label: clear
- Reason: The guidelines say this is not prohibited, since it does not infer emotions.
